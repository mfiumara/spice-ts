## Selection

- Candidates: 467; selected: 25; excluded: 442.
- Selected by licence: GPL-3.0-only 13, AGPL-3.0-only 12.
- Exclusions by reason: skipped-path 0, already-in-corpus 0, duplicate-content 31, licence 1, not-utf8 0, host-command 8, not-self-contained 195, no-analysis 190, ngspice-no-reference 17, directory-cap 0.
- ngspice probe: ngspice-47, 60 s bound; receipt `benchmarks/corpus/corpus-i/ngspice-probe.json` (SHA-256 `fc45a55721a5ba6552880b6a6df5b685ea01b2fde0c2910c4187f70ecb2be462`).

- Candidates: every git-tracked file at the pinned revision of each source, under the listed roots, whose name ends in .cir, .sp, .net, .ckt, .spi, .deck, .cki, .spice, .sim or .cir.out.
- skipped-path: the path is under a prefix the source table skips, with the reason given there.
- already-in-corpus: the bytes (or the bytes without a terminal newline) hash-match a fixture of an existing public corpus (every other directory under benchmarks/corpus, including corpus-h and ngspice-bugs).
- duplicate-content: the bytes hash-match an earlier candidate (sources in key order, paths sorted); the first is kept.
- licence: the deck carries a copyright or licence notice that the repository-wide licence cannot be assumed to cover (corpus-f rule, unchanged). Not committed.
- not-utf8: the bytes are not lossless UTF-8, so spice-ts cannot receive the identical deck through its string API.
- host-command: the deck runs shell or gnuplot commands on the host.
- not-self-contained: the deck loads another file (.include/.lib/OSDI/source) or names a sibling upstream file, so it cannot run unchanged in an isolated directory.
- no-analysis: no analysis card or control-block analysis command.
- ngspice-no-reference: ngspice-47 run on the identical bytes (batch mode, 60 s bound) did not exit 0 with at least one op/dc/ac/tran/pz/noise/disto plot in its raw file, so there is no reference to compare against. The probe result and ngspice's first error line are recorded in ngspice-probe.json. spice-ts is not run during selection.
- directory-cap: at most 16 decks per upstream directory (per source), first in path order, among decks that passed every rule above. Capped decks are listed below for later batches.

## Skipped sources

- eSim subcircuit and device-model library (`library/`, 2981 netlist files): Part definitions for eSim's schematic editor (one `.subckt` or `.model` per part plus its converter output), not example circuits; most have no analysis or reference sibling model files. Left for a later batch so this one does not consist mostly of single-part test benches.
- ISCAS-85/89 benchmark netlists (gate-level `.bench`): Not SPICE: running them needs a transistor-level translation with a chosen cell library (an adaptation). The transistor-level ISCAS c6288 multiplier that VACASK ships (`benchmark/c6288/ngspice/runme.sim`, `benchmark/vadistiller/c6288/`) is a candidate here; it loads its gate and model include files, so it is listed as `not-self-contained` below. The FreePDK45 CMOS gate decks of `ngspice-cmos` load their PDK models the same way.
- symbench/spice-datasets (https://github.com/symbench/spice-datasets, GPL-3.0 repository licence): Rejected: a scrape of third-party KiCad projects and of LTspice demo/example circuits. The repository licence cannot cover files whose authors never licensed them, and the LTspice examples are Analog Devices material without a redistribution grant.
- labtroll/KiCad-Simulations (KiCad/ngspice simulations by Holger Vogt): Rejected: the repository states no licence.
- Qucs-S examples (https://github.com/ra3xdh/qucs_s): The examples are Qucs schematics and qucsator netlists; the few `.cir` files are vendor device-model subcircuits without an analysis. Not surveyed further.
- EEcircuit (https://github.com/eelab-dev/EEcircuit, MIT): No netlist files are tracked: its example circuits live inside application source code, so extracting them would be an adaptation.
- Vendor application notes / LTspice example circuits and textbook circuits: Vendor and LTspice example terms do not grant redistribution; textbook netlists are embedded in prose (extraction is an adaptation). Not committed.
- Decks with their own copyright or licence notice in any source: Listed below as `licence` exclusions and not committed.
