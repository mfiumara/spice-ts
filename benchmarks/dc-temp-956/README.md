# DC TEMP regression (#956)

DC sweep targets now include case-insensitive TEMP in either dimension. Every temperature update runs existing device temperature hooks, including BSIM3 model/size cache reconstruction. Source waveforms and circuit temperatures are restored on success and failure. Resistor restoration uses circuit temperature, not effective instance TEMP/DTEMP. The implementation does not touch parser files, circuit.ts, aggregate receipts, tolerances, or original corpus decks.

## Reproduce

- `pnpm install --frozen-lockfile`
- `python3 benchmarks/dc-temp-956/generate.py`
- `pnpm -C packages/core exec vitest run src/analysis/dc-temperature-956.test.ts src/analysis/dc-sweep.test.ts src/analysis/step.test.ts src/temperature-ngspice-parity.test.ts`
- `pnpm build && pnpm lint`
- `spice-heavy pnpm exec tsx benchmarks/corpus/corpus-j/part2.ts`
- `spice-heavy pnpm exec tsx benchmarks/dc-temp-956/all-plots.ts`

The corpus command writes its historical receipt location. For this card its output was copied into before.json / after.json and the historical tracked files restored. No aggregate refresh. The runner imports built dist, so build before running it. The final after receipt records the implementation commit's core tree. All logs ending in .gz are real captured output (`gzip -dc FILE` to read).

RED commit 3764006f reproduces missing TEMP targets (3 failed, 1 passed). Its authored reference used a series resistor; after implementing the target, the series-diode default Newton stopping residual exceeded the original test assertions. The final authored reference instead uses an ideal voltage source directly driving an N=2 diode to isolate the temperature law from that convergence residual. Test tolerances and simulator tolerances were not relaxed. No public corpus deck was changed. Final targeted run: 112 tests pass across four files (six new tests). Build and lint pass. Full-suite validation is delegated to exact-head required GitHub CI, per this card's targeted-only local test instruction.

## All original plots, indexed comparison

all-plots.ts sources the byte-identical fixture in ngspice and exports dc1 through dc6 using only output wrapper commands. spice-ts runs that same original input and exposes all six via control.runs. The script verifies equal primary grids at every index and equal counts before computing errors without interpolation. It compares 16 signals per plot, both overall and separately for every secondary value. Full per-signal receipts are in all-plots.json.gz (gzip of generated all-plots.json).
