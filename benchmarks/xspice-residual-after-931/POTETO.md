# Poteto investigation evidence

Scope is diagnosis-only. Acceptance is five same-byte original executions,
explicit unsupported/failure buckets, matched-point metrics or nulls, source
licences and dependency closure, bounded owned execution, and a concrete next
reservation. No production fix, event-kernel design, or corpus rewrite.

Data shapes precede logic: an original has a manifest row, input/include hashes,
a reference process receipt, native typed result, and zero or more analysis
comparisons. A process receipt has command/cwd/stdin, exit/status, actual wall
seconds and stdout/stderr. A plot has kind, coordinate array and named vectors.
A metric has matched/reference/native counts plus max/RMS absolute/relative
errors, never a boolean inferred from exit zero.

Plan executed: pin fresh baseline; read unchanged inputs and native port/model
paths; export pinned upstream source; run five serial original comparisons;
repair only control readout driver while preserving failed attempt; recompute
samples offline; propose a model/port-layer slice; run local gates; publish PR
and route independent exact-head review. Stdlib Python owns budgets, hashes and
raw parsing. No new dependency or shared benchmark harness modification.

Deliberate limits: no interpolated waveform parity claim, no full measurement or
graphical plot parity claim, no production model prototype, no reusing historical
counts as current results. No separate witness is useful for the current first
blockers because original mode-1 cards and upstream hd port semantics are direct
and complete evidence of that dependency gap.
