# Issue 289 Xyce DC output receipt

This receipt covers the four unchanged Xyce primitive DC fixtures named in issue #289. It does not claim numeric parity or update the aggregate report.

## Root cause and fix

The failures did not come from missing circuit output vectors. The preprocessor evaluated brace notation inside full-line `*` comments before the tokenizer discarded those comments. Descriptive equations such as `{R2/(R1 + R2)}` and `{VCC - VBE}` therefore reached the parameter expression evaluator and failed on the device or source names `R2` and `VCC`.

RED commit `a32e372` added unchanged-fixture tests and reproduced four failures. GREEN commit `8dac3e4` makes the preprocessor preserve full-line comments without evaluating them. The device cards, requested outputs, parser options, and tolerances are unchanged.
